# Laboratory 01 - Welcome to the Cloud

## Mission Overview
This laboratory introduces the basic environment and responsibilities of a cloud infrastructure engineer. The activity focuses on using a Linux environment, organizing files, gathering system information, and documenting technical work.

## Objectives
- Access and use a cloud-based Linux environment.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.

## Activities Performed
- Accessed an Ubuntu Linux environment using KillerCoda.
- Created and configured the `kjose` Linux user.
- Verified sudo access.
- Gathered Linux system information.
- Created and organized the laboratory workspace.
- Created Markdown documentation.

## Skills Learned
- Linux command-line navigation
- Linux user management
- Basic system administration
- File and directory organization
- Markdown documentation
- Cloud-based Linux environment usage
