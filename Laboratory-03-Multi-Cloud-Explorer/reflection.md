# Reflection

## My Cloud Computing Experience

Among AWS, Microsoft Azure, and Google Cloud Platform (GCP), the cloud platform that impressed me most is AWS. I was impressed by the wide range of services that AWS provides for computing, storage, databases, networking, security, and other cloud workloads. I also found AWS interesting because it can support both small applications and large enterprise environments.

AWS, Azure, and GCP have many similarities. All three are major cloud computing platforms that provide services for virtual machines, object storage, databases, networking, identity management, and Kubernetes. They also provide global infrastructure that allows organizations to deploy applications and services in different geographic locations. Another similarity is that all three platforms provide scalable cloud resources that can be adjusted according to business requirements.

Business requirements have an important influence on cloud platform selection. The best platform depends on factors such as budget, existing technologies, application requirements, scalability, security, geographic availability, and the skills of the organization's IT team. For example, Azure is a strong choice for an organization that already uses Microsoft technologies, while GCP can be a good choice for AI and machine learning workloads. AWS can be suitable for organizations that need a broad range of cloud services.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud platform is not simply about selecting the most popular provider. I learned that I need to understand the client's specific needs and then match those requirements with the appropriate cloud services. Comparing AWS, Azure, and GCP helped me develop a better understanding of how cloud solutions can support different types of organizations.

My GitHub portfolio has also improved through this laboratory. I learned how to organize laboratory files, write documentation using Markdown, use Git for version control, and push my work to GitHub. My portfolio now provides a structured place where I can continue adding future cloud computing activities and demonstrate the technical skills I develop throughout the semester.
