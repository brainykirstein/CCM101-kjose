# Laboratory 03 - Multi-Cloud Explorer

## Mission Overview

This laboratory explores three major cloud platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). The activity focuses on researching cloud services, comparing providers, analyzing business requirements, and recommending appropriate cloud solutions.

## Objectives

- Explore AWS, Microsoft Azure, and Google Cloud Platform.
- Identify core cloud services.
- Compare cloud platforms.
- Analyze business requirements.
- Recommend appropriate cloud solutions.
- Continue developing my Cloud Computing Portfolio.
